# The Oxford-IIIT Pet Dataset - Image Classification

## Описание проекта

Проект посвящен классификации пород домашних животных на основе датасета **The Oxford-IIIT Pet Dataset**. Датасет содержит изображения 37 пород кошек и собак (примерно по 200 изображений на породу).

**Цель:** Сравнение эффективности различных архитектур нейронных сетей для задачи классификации изображений.

## Характеристики датасета

- **Количество классов:** 37 пород (25 пород собак, 12 пород кошек)
- **Размер изображений:** ~224x224 пикселей (вариативно)
- **Объем данных:** ~7,400 изображений
- **Разделение:** Стандартное разделение train/val (примерно 50/50)

## Архитектуры моделей

### 1. **VGG19**
- Глубокая сверточная сеть с 19 обучаемыми слоями
- Использует только сверточные слои и полносвязные слои
- Большое количество параметров (~143M)
- **Особенность:** Все сверточные слои заморожены, обучается только классификатор

### 2. **ResNet50**
- Остаточная сеть с 50 слоями
- Использует skip-connections для борьбы с затуханием градиента
- Среднее количество параметров (~25M)
- **Особенность:** Заморожены все слои кроме layer4 и классификатора

### 3. **EfficientNet-B0**
- Сеть с балансировкой глубины, ширины и разрешения
- Использует compound scaling
- Малое количество параметров (~5M)
- **Особенность:** Все слои заморожены, обучается только классификатор

### 4. **ModernCNN (Custom)**
- Легковесная архитектура с residual блоками
- 3 стадии с увеличивающимся количеством каналов (64 → 128 → 256)
- Использует ReLU активацию и опциональные SE-блоки
- **Особенность:** Полностью обучаемая с нуля

## Метрики оценки

- **Accuracy** - точность классификации
- **Loss** - функция потерь (Cross-Entropy)
- **Early Stopping** - остановка при отсутствии улучшений (patience=10)

## Результаты

### Сравнение качества моделей

| Модель | Параметры | Train Accuracy | Val Accuracy | Время обучения (epoch) |
|--------|-----------|----------------|--------------|----------------------|
| **VGG19** | 143M | 87.6% | 90.3% | ~25 мин |
| **ResNet50** | 25M | 91.7% | 93.4% | ~18 мин |
| **EfficientNet-B0** | 5M | 76.5% | 84.6% | ~12 мин |
| **ModernCNN** | 2.8M | ~% | ~% | ~мин |


### Анализ результатов

#### **ResNet50** - Победитель по точности
- Лучшая валидационная точность (93.4%)
- Хороший баланс между размером и производительностью
- Оптимальный выбор для большинства задач
